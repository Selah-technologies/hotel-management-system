# Decision records

Each important team decision gets one short file in this folder, as the team handbook requires. A record states the context, the options considered, the choice, and the date.

## How to add a decision

1. Create a file named D-NN-short-title.md, using the handbook decision number if there is one, otherwise the next free number.
2. Follow the structure of an existing record: Status, Recorded, Agreed by, Source, then Context, Options, Decision, Consequences.
3. Open a pull request into develop. Teammates who agree approve the pull request, and that approval is how their agreement is recorded.

## Status values

Open, Decided, Revisit (as in the handbook, Appendix B).
